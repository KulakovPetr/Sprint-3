# Bank Standard: Architecture Case Study

Архитектурный кейс по цифровой трансформации банка: проектирование MVP онлайн-открытия депозитов и целевой архитектуры с горизонтом развития на 12 месяцев.

## Цели проекта

- Запустить MVP оформления депозитов и накопительных счетов в онлайн-каналах.
- Подготовить архитектуру, позволяющую перейти от полуавтоматического процесса к fully digital flow.
- Снизить операционную нагрузку бэк-офиса.

## Состав репозитория

### `Task1` - AS-IS анализ

- Карта IT-ландшафта.
- Схема интеграций между системами.

### `Task2` - Архитектурные требования

- FURPS+ с функциональными и нефункциональными требованиями.
- Ограничения и архитектурные драйверы.

### `Task3` - ADR по MVP депозитов

- C4 Context + C4 Containers.
- Обоснование решений: выделенный депозитный сервис, API Gateway, Kafka.
- Анализ альтернатив, рисков и компромиссов.

### `Task4` - ADR и дорожная карта развития

- C4 Context + C4 Components для передачи ставок в кол-центр.
- Декомпозиция задач по системам.
- Roadmap внедрения (MVP + целевое состояние).

## Инструменты и подходы

- ADR (Architecture Decision Records)
- C4 (PlantUML)
- Draw.io
- FURPS+
- Event-driven интеграции (Kafka)

## Для кого полезен этот репозиторий

- Архитекторам и системным аналитикам как пример учебного end-to-end кейса.
- Командам, планирующим поэтапную цифровую трансформацию legacy-ландшафта.
- Рекрутерам как демонстрация навыков структурирования требований и архитектурного мышления.
